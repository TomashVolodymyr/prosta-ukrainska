# prosta-ukrainska

Скіл для Claude, який змушує модель писати простою, читабельною українською.

Без нього Claude українською пише так само, як англійською: довгі речення з тире, переліки через кому в одному рядку, дужки з фактами, кальки на кшталт «на даний момент» і «являється». Такий текст доводиться перечитувати двічі. Скіл задає правила, за якими текст читається з першого разу.

## Що робить

- Три і більше однорідних речей завжди йдуть списком, а не через кому.
- Речення до 15 слів, одна думка на речення.
- Тире всередині речення замінюється крапкою.
- Дужки з фактами, двокрапки між реченнями і суцільні блоки тексту заборонені.
- Заборонений список канцеляриту, кальок і слів-прикрас: «даний», «являється», «на протязі», «чесно», «насправді», «потужний», «ефективний» та інші.
- Текст, який людина скопіює далі (лист, повідомлення), видається окремим блоком, розбитим на абзаци.
- Перед видачею модель проходить перевірку з 11 пунктів.

Команда `/prosta-ukrainska перепиши` переписує попередню відповідь за цими правилами.

Повний текст правил: [prosta-ukrainska/SKILL.md](prosta-ukrainska/SKILL.md).

## Встановлення

### Claude (вебверсія і застосунок)

1. Завантажте цей репозиторій як zip або запакуйте теку `prosta-ukrainska` у zip.
2. У Claude відкрийте Settings → Capabilities → Skills.
3. Завантажте zip. Скіл з'явиться в списку і працюватиме в усіх чатах.

### Claude Code

Скопіюйте теку `prosta-ukrainska` у `~/.claude/skills/`:

```
cp -r prosta-ukrainska ~/.claude/skills/
```

У новій сесії скіл доступний як `/prosta-ukrainska`.

### Інші інструменти

Скопіюйте текст SKILL.md нижче заголовка в системні інструкції, `AGENTS.md` або правила вашого редактора.

## Звідки правила

Основа — принципи plain language з англомовних скілів для Claude ([plain-writing-skill](https://github.com/docwriter-org/plain-writing-skill), [claude-plain-english-skill](https://github.com/b1rdmania/claude-plain-english-skill)). Жоден з них не працює з українською: списки заборонених слів і приклади в них англійські. Тут правила переписані під українську мову і доповнені тим, що в українському тексті Claude ламається найчастіше: тире, кальки, переліки в рядок.

Правила живі. Якщо Claude з цим скілом усе одно пише нечитабельно, відкрийте issue з прикладом «було / має бути».
